# website-dev

A polished one-page marketing site starter for a modern digital studio.

## What is included
- Responsive landing page
- Hero section with metrics and visual dashboard
- Services, work, about, and contact sections
- Subtle scroll-reveal animations
- Pure HTML/CSS/JS setup

## Run locally
Open `index.html` directly in a browser, or serve it with a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
